# Shelf-Life XGBoost V2-Log

Isolated experimental model using `log1p` target training and `expm1` inverse transformation. Original data and prior model directories are read-only. Run `python train.py` using the project shelf-life virtual environment in the repository root. The script refuses to overwrite this directory.

See `reports/` and `metrics/` for the same-row V1 comparison and limitations. No production integration is performed.
