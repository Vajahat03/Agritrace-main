# Shelf-Life Regression Dataset Research

Research checked 25 September 2026. “Verified” below distinguishes repository/paper descriptions from direct inspection of a downloaded data file. Public web access exposed official metadata and explicit target definitions, but did not provide file bytes in this session. No data was downloaded.

## Current Problem

The existing 43,529 auxiliary records describe images, freshness/spoilage classes, or environmental/postharvest observations. They do not contain a supported numeric shelf-life or failure-day endpoint. The 14,160 AgriFreshNET images have approximate shelf-life ranges, not measured per-sample numeric targets; Mendeley spoilage records support classification/environment analysis; and the 18 Zenodo longitudinal observations have no defined failure endpoint. Therefore valid numeric regression rows remain zero. No values should be inferred from freshness classes or assigned ranges.

## Verified Numeric Targets

- **Dryad tomato fruit quality / heterosis:** source documentation explicitly defines SL as elapsed days from harvest until first visible deterioration at 25 ± 3 °C. Target is measured at fruit level according to the described sampling, but exact raw-file rows/columns have not been independently checked because the workbook download was not performed.
- **Hass avocado ripening:** repository documentation explicitly identifies stage 4 as the end of shelf life, with daily day and sample identifiers. A failure day and remaining days can be derived from each fruit’s observed trajectory. The metadata sheet itself was not downloaded, so actual target coverage/record count still needs file verification.
- **Dryad tomato neem/beeswax trial:** source identifies a dedicated ShelfLife workbook and study of shelf life but its numeric contents and target definition remain unverified because official file streams returned 403. Treat as promising, not yet verified numeric data.

No candidate reached direct file-bytes verification in this research pass. Accordingly, no candidate is yet approved for ingestion. The first two targets above are source-verified and warrant official file inspection on acquisition.

## Best Candidates

The Dryad heterosis dataset offers the clearest explicitly defined tomato endpoint: days to first visible deterioration, plus physical fruit traits. It is a single-produce study and likely requires tomato-specific modeling or careful transfer evaluation. File-level schema and sample counts must be checked before use.

The Hass avocado dataset has a clearly operational failure threshold, daily repeated observations, individual sample numbers, and controlled temperature/RH groups. It may support remaining-life regression from observation day to the documented stage-4 endpoint. Split data by fruit, not image, and resolve fruits that never reach stage 4 in observed data as censored rather than assigning an invented endpoint.

The neem/beeswax Dryad study has useful treatments, measured ambient storage context, replication, and a workbook specifically named for shelf life. Its official download is currently blocked, and the shelf-life value may be summarized at treatment/replicate level rather than fruit level.

## Rejected Candidates

- Existing AgriFreshNET range annotations: approximate produce-level ranges, not measured sample-specific numeric targets. Preserve as auxiliary labels; do not convert range midpoints into regression targets.
- Mendeley spoilage datasets with Good/Bad, Fresh/Spoiled, or freshness-stage labels: classification labels do not encode numeric time-to-failure.
- FGrade tomato dataset: ten visually assessed freshness classes formed by volunteer voting. Class IDs are not shelf-life days; reported differing harvest dates further prevent treating class as an absolute time target.
- Mango Shelf-Life Dataset: repository and follow-up study describe image ripeness-stage classification only; no numeric target or verified sample/day trajectory.
- Zenodo e-nose tomato dataset: day-indexed quality/sensor observations may be useful features, but accessible metadata gives no defined shelf-life or failure endpoint. Observation day is not itself shelf life.
- Zenodo 18-observation tomato imaging dataset: repeated observations of one fruit and environmental context, but no defined endpoint, so no defensible shelf-life target.
- Synthetic shelf-life datasets or arbitrary generated day values: rejected for lack of measured research provenance. No such source was accepted or downloaded.

## Recommended Acquisition Order

1. **Dryad tomato fruit quality / heterosis** — first attempt its official record/API/file route for the 3.32 MB raw-data XLS and README. The endpoint definition and provenance are clear; tomato-only scope and limited environmental features are the main constraints.
2. **Hass avocado Mendeley dataset** — download its official workbook and confirm per-fruit trajectories, coverage to stage 4, and exact storage groups. Strong repeated-measures structure and temperature/RH metadata; single produce and endpoint censoring need care.
3. **Dryad neem/beeswax tomato trial** — retry only normal official page/API/download routes later. Currently file streams return 403. It has treatment and ambient condition breadth, but less certain outcome granularity.
4. **Figshare tomato fungicide workbook** — acquire and inspect the actual XLSX and study methods; keep out of regression until a numeric endpoint and its definition are confirmed.
5. **Zenodo e-nose and hot-water/air tomato records** — inspect official files/source papers for explicit failure thresholds and specimen mapping. Storage-day data alone is insufficient.

For each acquisition, record file checksums, sheet/column names, row counts, units, target definition, specimen mapping, and censored observations before any pipeline integration. Do not modify the existing auxiliary dataset or produce training rows until those checks pass.
